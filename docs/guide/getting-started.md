# Getting Started

This guide walks you through setting up a Solidocs site.

## Requirements

- Node.js 24 or later
- pnpm 10

## Installation

Install the package:

```bash
pnpm add solidocs
```

### Peer dependencies

You will also need `solid-js` in your project.
